# Common Foundry (CMFD)

Common Foundry is a GPU proof-of-work network. Mainnet mining began October 3,
2026. Wallets, transfers, nodes, mining, and the public explorer are available.
The GPU rental marketplace is in beta. Customer-paid AI inference remains in
development as a separate service layer; mining work is not a customer inference job.

## Monetary policy

There was no premine or token sale. During the bootstrap, block rewards are split
70% to miners, 25% to stewardship, and 5% to the community. Issuance declines by
block height, followed by a permanent 5 CMFD miner-only tail. Transaction fees
are burned. The tail is perpetual, so there is no hard maximum supply.

Read [the emission rules](https://commonfoundry.ai/docs/emission.md) and current
release materials for the precise rules. Mining and GPU renting do not promise a profit.
