Public API · updated November 5, 2026

Read public chain data.

The explorer provides public GET endpoints for supply and a bounded chain snapshot. No registration, login, API key, or wallet unlock is required for these documented reads.

Discover the service

Base URL: https://explorer.commonfoundry.ai. Use the API catalog to find this service, the OpenAPI description for request and response details, and authentication guidance for the access model.

Supply: GET /api/supply

Returns total and circulating CMFD supply, burned fees, the observed height and tip, and the balances excluded from the circulating figure. Circulating supply subtracts the current steward and community fund balances. CMFD amounts have eight decimal places; integer atom amounts are strings. Use decimal or integer arithmetic. The permanent tail means there is no hard maximum supply.

curl https://explorer.commonfoundry.ai/api/supply

Compatible assistants can use the public MCP service for status, supply, and documentation reads.

Chain snapshot: GET /v1/explorer

Returns network identity, accepted and validated heights, the current tip, connected peers, mempool information, and bounded recent block and transaction summaries. Read height and network fields before interpreting activity; a snapshot is a point-in-time observation.

curl https://explorer.commonfoundry.ai/v1/explorer

Usage and availability

Cache responses when appropriate and avoid tight polling loops. On HTTP 429, honor Retry-After when present. Back off on network errors or 5xx responses and retry later. Additional JSON fields may be added; clients should tolerate them. The OpenAPI file covers the two public endpoints above rather than every internal or application-specific interface.

Wallets and rentals

Public data access does not grant permission to sign transactions, unlock wallets, spend funds, or rent hardware. Those actions belong in the wallet or renter application under the user's control. See the guides for those workflows. Never submit keys or passphrases to the public data endpoints.
