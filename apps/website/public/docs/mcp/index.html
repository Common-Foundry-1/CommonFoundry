Public MCP · service 0.1.0

Give your assistant a reliable starting point.

Compatible MCP clients can read Common Foundry's public mainnet observations and maintained guides. No account or API key is required.

Connect

In your client's remote MCP server settings, add https://commonfoundry.ai/mcp using Streamable HTTP and no authentication. Client setup varies; use the client's own connection instructions. This endpoint supports current MCP requests and stateless 2025-era clients. The older standalone HTTP+SSE transport and persistent sessions are not provided.

The server card describes discovery metadata. Server-card discovery is an emerging convention; connected clients should use the runtime tool and resource lists.

Available tools

  • get_network_status: observed mainnet identity, heights, tip, peers, and mempool counts.
  • get_supply: total and circulating CMFD supply and burned fees. Decimal quantities and integer atoms remain strings.
  • read_guide: the project overview, mining setup, ForgeMatrix, GPU renting, API use, white paper context, or MCP connection guide.

The same maintained guides are exposed as MCP resources. For example, ask your connected assistant to “read the mining setup guide” or “report CMFD's current public network status and the observation time.”

Interpret the results

Data tools return their source URL, fetch time, and a 15-second maximum cache age. They report the public explorer's observations and check expected network identity and response shape. This adapter does not independently validate consensus proofs. Heights and confirmations can change after a reorganization.

Limits and access

The service accepts bounded requests up to 32 KiB and bounds upstream response size and timeout. Fixed status and supply reads share a short cache and coalesce concurrent requests. A per-isolate burst guard can return HTTP 429 with Retry-After; it is not a global rate-limit guarantee. Back off on errors.

Server-to-server clients may omit Origin. Browser requests are validated against the site's origins, ChatGPT, Claude, and local development origins. Browser clients with other origins need a compatible server-side connection. Credentials are not used.

Tools are read-only. Wallet creation or unlocking, transaction signing, fund transfers, miner control, and rental control belong in their respective applications under the user's authorization.
