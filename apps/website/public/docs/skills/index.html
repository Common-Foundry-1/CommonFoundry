Review and install

  1. Read the linked SKILL.md before installing it.
  2. Use your assistant's documented skill import mechanism. If it uses skill directories, create a directory matching the skill's name and save the file inside it as SKILL.md.
  3. Ask for the relevant task, such as “verify this CMFD release before installation” or “diagnose why my CMFD node is behind.” Supply the version and platform when available.

Installing a skill does not grant it credentials or authorize mining, restarts, transfers, or rental changes. Use the authorization and context of the task. These files contain instructions and references; no executable installer or bundled scripts are provided.

Discovery and integrity

The discovery index follows Cloudflare's draft Agent Skills Discovery 0.2.0 format and lists a SHA-256 digest of each served file. Clients can hash the downloaded bytes and compare them with the digest. A digest detects mismatched content; it is not a separate signature or proof of publisher identity.

Discovery support varies by client. Publishing these files does not automatically install them in ChatGPT or other assistants. For live public data and guides, compatible clients can connect to the read-only MCP service.
