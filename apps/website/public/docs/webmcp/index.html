Browser tools · experimental pilot

Read guides with a browser assistant.

On supported browsers, Common Foundry's public documentation exposes two read-only WebMCP tools: read the current guide and find related guides or setup skills.

Checking browser tool support…

Try a guide task

Open the mining guide and ask a compatible browser assistant to read the current page, or find a guide about release verification. The assistant must support WebMCP and have the browser permissions its own product requires.

  • cmfd_read_page returns the current public guide's title, source URL, headings, and bounded text.
  • cmfd_find_guide searches a maintained local index of guides and skills by topic.

These tools only read public documentation. They do not start mining, access wallets, sign transactions, control rentals, or install software.

Availability

WebMCP remains an evolving browser feature. This pilot uses document.modelContext.registerTool when the browser exposes it. Unsupported browsers continue to display the normal guides. No browser flags, extensions, or permissions are changed by this page.

For live public chain data and maintained guides through a remote connection, use the MCP service. WebMCP and remote MCP have different client requirements.

Updated November 5, 2026. See the browser API documentation for the current experimental API.
