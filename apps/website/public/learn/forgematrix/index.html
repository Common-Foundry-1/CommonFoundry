What does ForgeMatrix do?

ForgeMatrix is Common Foundry's proof-of-work function. Miners compete by evaluating a fixed, public, matrix-heavy computation bound to each candidate block. A winning block carries a proof and output that other nodes check under the network's rules.

What is computed?

The mainnet profile uses 384 sequential layers of 4,096 × 4,096 matrix computation over 128 rows in the KoalaBear field, against a fixed model bank. The work is deterministic and tied to the block candidate. See the consensus specification for exact rules.

What do nodes check?

Each block carries a large transparent proof. Current upgraded nodes also re-execute new blocks' work above the release checkpoint before accepting them, as described in the mainnet release notes and user guide. This work can run on a CPU; an ordinary wallet or node does not need a mining GPU.

Is mining itself useful AI inference?

No. ForgeMatrix secures block ordering and settlement. Customer-paid AI inference is a separate service under development. Mining a block does not mean that a customer received an inference result, and an inference receipt would not prove that a model answer is correct.

The public source and tests make the mechanism inspectable. They do not amount to an independent security audit or prove that every hardware and operational configuration is qualified.
