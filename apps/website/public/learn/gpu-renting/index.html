How does GPU renting work?

Common Foundry's GPU marketplace is a beta service separate from mining. A renter chooses an available host machine, funds a local renter wallet with CMFD, confirms a quoted deposit, and connects to the rented container over SSH.

  1. Check the live listings. Availability, hardware, host prices, and test records change. A listing is not a reservation.
  2. Get the renter app. Use the downloads and signed checksums linked from the marketplace page. The app creates a separate spending wallet on your computer.
  3. Review the quote. The app shows the required deposit before you confirm. Payment proceeds as the rental runs; unused deposit returns to the renter wallet when you stop.
  4. Connect and monitor. The app supplies an SSH command pinned to the host key. The marketplace page explains the included templates and what the host's test record means.

Current limits

The marketplace is in beta. Hosts are Common Foundry's own machines for now, and renters connect through a Singapore relay. The marketplace page shows the current list and explains measured hardware, disk quotas, and transfer limits. Check it immediately before paying.

GPU renting, mining rewards, and customer-paid inference are different activities. Renting a GPU does not generate mining rewards by itself, and this beta is not a claim that the planned inference market is complete.
