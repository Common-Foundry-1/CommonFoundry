Common Foundry guides · updated November 4, 2026

Start with the facts.

Common Foundry (CMFD) is a live proof-of-work network where miners use GPU matrix computation to compete for blocks. Wallets, transfers, nodes, mining, and a public explorer run on mainnet. A GPU rental marketplace is in beta. Customer-paid AI inference is a longer-term service under development.

Mining work secures the chain; it is not a paid customer inference job. A mining reward or GPU rental is not a promised profit. Check the current release notes, hardware requirements, costs, and risks before participating.

What is available now?

  • Mainnet: mining opened October 3, 2026. Inspect blocks on the public explorer.
  • Wallets and nodes: find signed desktop packages and release notes on the release list. The web wallet is also available.
  • GPU renting: the marketplace beta lets renters use a listed host machine when one is available. Availability and prices change.
  • Customer-paid inference: this remains in development as a separate service layer.
