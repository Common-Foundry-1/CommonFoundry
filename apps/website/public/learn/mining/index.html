Mining guide · updated November 4, 2026

How do I start mining CMFD?

Get the current signed mainnet package, verify it, check your GPU against that release's instructions, and choose a solo or independent pool setup. Mining needs a suitable GPU; a wallet and ordinary node do not.

  1. Read the current release notes. The v1.0.20 desktop release is the newest mainnet desktop release as of this update. Miner packages and supported hardware may have different version requirements; check the full release list before downloading.
  2. Verify before running. Follow the release verification instructions and compare the signing key fingerprint with the public release key. Verify the signed checksums and the package you downloaded.
  3. Set up a wallet. Use the web wallet or desktop wallet. Preserve your backup and passphrase; losing them can mean losing access to your coins.
  4. Choose mining mode. Follow the miner package's current instructions for solo or pool mining. If using a pool, check its operator, fee rules, payout terms, and current status independently.
  5. Check accepted work and payouts. Use your miner output, the pool's dashboard if applicable, and the block explorer.

What hardware and costs should I expect?

Compatibility and performance depend on the miner build, GPU, driver, memory, and operating system. Confirm your exact setup against current release notes and ask for a measured result from the community if it is unlisted. Budget for electricity, hardware wear, internet service, and any pool fee. Block rewards vary with network competition; no earnings estimate is guaranteed.

The full model inputs are approximately 6.4 GB. Some solo mining paths require substantially more disk space for prepared files. Check the current package instructions and available disk space before starting. A successful test on one GPU does not qualify another GPU or configuration.
