# Public testnet v0.2.0 proof timing on the local RTX 5090

The benchmark used the anonymously downloaded v0.2.0 Linux kit (archive
SHA-256 `382862da73feac25eac748348f1e71f4e5e6f06c8bb91183346afe233bff6615`),
the pinned 61.2 GB inputs already cached on this rig, and the public testnet
network ID `8a34c0d9eaa92c5eaec4af7fe146afdfa2ab6859918b7deb0c97e0a1f600d6d1`.
Before proving, the RTX 5090 read back 7001 MHz memory and a 480 W limit while
owner mining was stopped. The benchmark did not change clocks or power settings.
The pool caught up to public height 2 before mining the fresh height-3 block.

| Stage of the clean height-3 winner | Seconds |
| --- | ---: |
| Miner search for the winning nonce | 1.101 |
| Pool full-work replay of that nonce | 8.702 |
| Complete proof-worker request | 9.073 |
| Online GPU proof stage within that request | 4.460 |
| Pool evaluation from received share through proof ready for submission | 18.013 |
| Local node submission/admission after evaluation | 0.465 |

The compact packet was **5,683,962 bytes**. The prover reported a **9.125 GiB
sampled process GPU peak**. The pool accepted block
`de0badec970ad4b75c034e8ad5520b9ae498733f70495f92832de220a56ec124`
at height 3. The public Proxmox audit seed advanced to height 3, and a
separate proof-only node downloaded the same tip, reported healthy storage,
used in-process proof verification, and had `work_rule: null`.

This rig has one GPU. During the first height-2 run, concurrent miner and
proof-worker GPU allocations tripped the worker's 13 GiB guard three times.
After the miner stopped, the pending proof succeeded with a 4.102-second
online stage, but the retries make its total wall time unsuitable as a clean
benchmark. For height 3, a benchmark-only monitor sent SIGINT to the testnet
miner three seconds after it logged the winning nonce. The pool retained the
submitted share, replayed it, and proved it with the GPU free. No proof-worker
restart occurred in that clean run.

The **4.460 seconds** is the hot online GPU stage. The mining-relevant complete
proof request was **9.073 seconds**, and share evaluation plus local admission
was about **18.48 seconds**. Thus this test meets a 5-second *GPU-stage* target,
while the full winning-block path still has room for optimization. A 32 GB
5090 result does not by itself qualify a 16 GB card or simultaneous mining and
proving on one card.

After the test, the isolated pool, testnet miner, handoff monitor, and CPU
verification nodes were stopped. The original `PearlMiner` task XML fingerprint
remained `29f227b4ede69cc6a924c59cfd842c406cede1fe4fc1075f5707652dfb5c7922`;
its task was running again at 99% GPU use and 7001 MHz memory. WildRig NG
1.0.0s reported 13 accepted shares and zero rejects after restoration. The
saved MSI Afterburner profile read 65% of this card's 800 W ceiling and the
live running limit read 520 W. This saved profile was observed after the test;
it is not claimed as the earlier stopped-state 480 W readback. The benchmark
did not edit the profile or successfully issue a power-limit command.
