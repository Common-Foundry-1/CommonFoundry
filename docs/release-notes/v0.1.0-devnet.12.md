# Common Foundry v0.1.0-devnet.12

Devnet-12 is a private testing release focused on easier peer onboarding, better diagnostics, and broader GPU-miner support. It does not activate the unfinished production ForgeMatrix succinct-proof profile.

## Changes

### Peer setup and wallet networking

- Added a persistent peer manager to the desktop wallet.
- Testers can add, remove, and reset peers from the Network screen without editing launch commands.
- Numeric IP addresses default to TCP port `18444` when the port is omitted.
- Saved peer settings are validated before use and persist across wallet restarts.
- The community bootstrap peer remains the default and can be restored with one click.

### Node diagnostics

- Added structured tracing to the standalone node and embedded wallet node.
- The wallet keeps a debug-level log in its data directory while console verbosity remains operator-controlled.
- Improved startup reporting for bind, peer configuration, and public-peer mode.

### GPU mining

- Increased CUDA work submitted per scheduling cycle and reduced host-side launch overhead.
- Added adaptive launch sizing and explicit throughput controls for multi-GPU rigs.
- Added an OpenCL backend for Intel Arc GPUs, including device enumeration and backend selection.
- Retained NVIDIA support for Volta, RTX 20-, 30-, 40-, and 50-series GPUs through native CUDA targets plus PTX fallback.
- Standalone miner packages include editable Windows and Linux launchers.

## Compatibility and operator notes

- Devnet-12 uses the existing Devnet-0 chain and P2P protocol. Existing Devnet wallet data is preserved.
- Replace the application binaries; do not delete the wallet data directory.
- Allow inbound TCP `18444` only on nodes intended to accept public peers. Wallet RPC remains local.
- Windows binaries are not code-signed, so Windows may show an unknown-publisher warning.
- Intel Arc mining requires a working vendor OpenCL runtime. NVIDIA mining requires a compatible NVIDIA driver.

## Proof-system status

- Devnet consensus continues to validate the small reference ForgeMatrix relation by full recomputation.
- The custom production succinct-proof work is still research-only and is not activated by this release.
- Production activation remains fail-closed until an unchanged full-size proof completes end to end and records proof size, proving time, verification time, and peak memory.

## Quality gates

The prepared binaries must not be distributed until all of these checks pass for the exact release commit:

- Rust 1.88 workspace compatibility check.
- Rust formatting, Clippy with warnings denied, and full workspace tests.
- Frontend typecheck, unit tests, and production build.
- Windows and Linux desktop builds.
- Windows and Linux node and standalone-miner version checks.
- CUDA differential validation and packaged architecture inspection.
- Package extraction and launcher smoke checks.
- SHA-256 manifest verification against the final release directory.
