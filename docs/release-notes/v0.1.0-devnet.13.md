# Common Foundry v0.1.0-devnet.13

Devnet-13 is a private testing candidate that combines the Devnet-12 wallet,
networking, and miner improvements with the latest production-proof research.
It remains on the existing Devnet-0 chain and does not enable the unfinished
production ForgeMatrix proof profile.

## Changes

### Wallet networking and diagnostics

- Added a persistent peer manager to the desktop wallet. Testers can add,
  remove, and reset outbound peers from the Network screen.
- Numeric peer IPs default to TCP port `18444`; saved settings are validated,
  applied immediately, and restored after restart.
- Added structured node logging and clearer startup diagnostics while keeping
  wallet RPC local to the computer.

### Standalone mining

- Retained native CUDA targets for Volta and NVIDIA RTX 20-, 30-, 40-, and
  50-series GPUs, with a `compute_70` PTX fallback.
- Increased CUDA scheduling depth and exposed throughput controls for
  multi-GPU rigs.
- Added a runtime-loaded OpenCL backend for Intel Arc, device enumeration, and
  explicit backend selection.
- Windows and Linux miner packages retain editable launchers and direct
  node-template mining; the miner does not maintain a second blockchain.

### Succinct-proof research

- Replaced the first eight aggregate transition, mapped-inverse, matrix, and
  wiring fold files with authenticated source-backed logical views.
- Each view lineage binds the transcript context, source digest, mapped-table
  identity where applicable, original parent lineage, role, and every fold
  challenge. Source corruption and role substitution fail closed.
- Dense, ordinary scratch, and source-view paths produce exactly the same proof
  bytes. Ordinary authenticated scalar artifacts resume at generation nine.
- The exact n=33 aggregate-stage scratch projection fell from
  110,935,310,868 bytes (about 103.3 GiB) to 55,898,080,516 bytes (about
  52.1 GiB). That total contains 52,600,404,004 bytes of retained sources and
  a 3,297,676,512-byte fold peak.
- Two fresh n=19 release runs preserved the 84,717-byte proof, measured
  108.297--108.371 seconds proving and 7.950--8.939 seconds verification,
  observed the same 50,262,684-byte full-prover scratch peak against a
  3,139,300-byte aggregate-stage projection, and retained zero scratch.

## Compatibility and operator notes

- Devnet-13 uses the current Devnet-0 chain, P2P protocol, wallet data format,
  and TCP port `18444`. Existing wallet data should be preserved.
- Replace application binaries; do not delete the wallet data directory.
- Windows binaries are not code-signed and may show an unknown-publisher
  warning.
- Intel Arc mining requires the vendor OpenCL runtime. NVIDIA mining requires a
  compatible driver.

## Quality boundary

- The complete Dory/ForgeMatrix consensus suite passed: 238 tests, with four
  release-only tests ignored, plus eight adversarial consensus tests.
- Exact proof-equivalence, lineage-mutation, authenticated-source corruption,
  projection-accounting, and n=19 release benchmark checks passed.
- Workspace formatting, all-feature Clippy with warnings denied, and Rust 1.88
  compatibility passed before release integration.
- Final workspace, frontend, Windows/Linux package, GPU backend, archive, and
  checksum results are recorded in the private release `BUILDINFO.txt`.

## Production status

Production activation remains fail-closed. The n=33 figure above is an
executable projection, not a completed production proof. Mainnet still requires
the final model commitments, one unchanged n=33 end-to-end proof with proof
size, proving time, verification time, peak memory and disk recorded, independent
soundness review, adversarial public testing, and external audit.
