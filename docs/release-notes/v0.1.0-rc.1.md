# Common Foundry v0.1.0-rc.1 — RCNet-1

This is an experimental release candidate for the RCNet-1 launch rehearsal.
It is not mainnet and RCNet coins have no intended monetary value.

## Included

- Pinned RCNet-1 network identity and public bootstrap endpoint.
- ProductionV4 consensus selection with the full-shape ForgeMatrix transparent proof.
- Windows and Linux node and desktop-wallet packages.
- Windows and Linux certificate-pinned ProductionV4 pool-miner packages.
- Encrypted wallet storage, authenticated backups, restore, migration, and locking.
- Exchange-oriented JSON-RPC, deposit, withdrawal, confirmation, reorganization,
  fee, health, and integration-test surfaces.
- Canonical runtime attestations, checksums, SBOM, and build provenance.

## Activation scope

The release is authorized by a signed single-producer RC approval. The approval
explicitly does not claim independent reproduction, external audit, or mainnet
authorization. Those remain later gates.
