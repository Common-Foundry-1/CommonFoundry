# Common Foundry v0.1.0-rc.2 — Wallet input hotfix

This RCNet-1 hotfix corrects the desktop wallet passphrase dialog. It is not
mainnet, and RCNet coins have no intended monetary value.

## Fixed

- Passphrase fields retain keyboard focus while background status polling
  rerenders the wallet.
- Passphrase guidance and validation now use the user-facing minimum of 12
  characters instead of describing UTF-8 storage bytes.
- Unusually long passphrases are rejected without exposing implementation
  terminology.

The RCNet-1 network identity, consensus rules, bootstrap endpoint, wallet data
format, and encrypted-backup format are unchanged from `v0.1.0-rc.1`.
