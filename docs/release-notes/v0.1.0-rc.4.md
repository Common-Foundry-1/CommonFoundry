# Common Foundry v0.1.0-rc.4 — automatic RCNet runtime preparation

This RCNet-1 release candidate fixes the Windows installer path that could
start the wallet without its authenticated ProductionV4 runtime. It is not
mainnet, and RCNet coins have no intended monetary value.

## Fixed

- The Windows installer now includes the authenticated runtime manifest,
  fixed artifact record, and resumable runtime preparation script.
- When the approximately 6.4 GB model bank is missing, the installed wallet
  opens a PowerShell progress window, downloads and authenticates the pinned
  bank, and then continues wallet startup.
- Interrupted downloads remain resumable. A failed preparation reports a
  retryable error and never permits the wallet to use unauthenticated files.

The ProductionV4 model bank, RCNet-1 network identity, consensus rules,
bootstrap endpoint, wallet data format, and encrypted-backup format are
unchanged from `v0.1.0-rc.3`.
