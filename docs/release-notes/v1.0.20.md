# Common Foundry v1.0.20

While the desktop wallet is open, it can automatically consolidate mature, unreserved outputs when the owner opts in. It waits for wallet unlock, healthy storage and block checks, completed catch-up when that service is active, a connected peer at the same tip, and settled wallet activity. Each batch uses at most 128 inputs, waits for another block and at least 15 minutes before the next attempt, and burns the standard 0.1 CMFD fee only when it is at most 1% of the selected inputs. Manual consolidation remains available.

During wallet opening and unlock, the wallet now shows measured startup phases, scanned history counts, elapsed time, storage errors, and copyable support details. Progress reporting does not wait behind the custody or node state locks.

Existing wallets, keys, chain data, network identity, mainnet checkpoint, proof format, and consensus rules remain unchanged. Release qualification and final package signatures must be verified against the exact published artifacts.
