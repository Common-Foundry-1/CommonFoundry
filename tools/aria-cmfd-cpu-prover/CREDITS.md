# CPU pool credits

Stefan and AriaPool authored the original CPU share verifier, CPU compact prover, AVX-512 VNNI replay kernel and pool integration.

Common Foundry contributed the subsequent replay-kernel optimizations, fixed-bank opening reductions, parallel commitments, Windows CPU placement, replay trace reuse on Linux and Windows, and the Linux prover scheduling, sumcheck and sparse-read optimizations. The project distributes the combined source under its MIT license.
